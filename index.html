Delivery path

One artifact progresses through explicit verification and approval boundaries. A failed gate stops promotion.

01 / INTEGRATE

Build & test

Install locked dependencies; run real backend tests against MongoDB.

02 / PACKAGE

Container image

Build a versioned image and publish it to the configured registry.

03 / DEPLOY

Staging slot

Release into an isolated Azure App Service deployment slot.

04 / VERIFY

Readiness check

Require a successful HTTP readiness response; deployment fails closed.

05 / REVIEW

Jira & approval

Create a review issue, then require human authorization to promote.

06 / PROMOTE

Production swap

Use an App Service slot swap only after prior stages succeed.

Design constraints

This is an infrastructure and application reference, not a claim of an independently verified live Azure deployment. Cloud resources, access policies, and external integrations need their own environment-specific acceptance tests.

  • Required secrets live in Azure variable groups, never in pipeline source.
  • Failed smoke checks block promotion instead of silently continuing.
  • Production requires an explicit human approval step.
  • Application startup checks MongoDB connectivity and guards API routes.
